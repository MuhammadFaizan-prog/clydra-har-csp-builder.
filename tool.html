Record your own HAR

  1. Open your site, then DevTools (F12) → Network.
  2. Tick Preserve log, reload, and click through the flows you care about.
  3. Right-click the request list → Save all as HAR. Include response content if offered, so inline scripts can be hashed.

The file is read in this tab and never uploaded.
